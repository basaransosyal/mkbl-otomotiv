1. Gizli GitHub Depo Erişimi (Private Repo & SSH Deploy Key)

Projenin kaynak kodları güvenlik amacıyla GitHub üzerinde Private (Gizli) depoda tutulmaktadır. Depo kamuya açılmadan sunucunun otomatik kod çekebilmesi için SSH Deploy Key (Önerilen) kullanılır:

🔒 GÜVENLİK AVANTAJI: Bu yöntem sayesinde kodlarınız dış dünyaya %100 kapalı (Gizli) kalır. Sunucuya tanımlanan sadece okunabilir (Read-Only) SSH anahtarı ile tüm güncellemeler otomatik olarak sunucuya aktarılır.

Adım 1.1: GitHub Depo Adresleri

  • HTTPS URL: https://github.com/basaransosyal/mkbl-otomotiv.git
  • SSH Clone URL (Önerilen): git@github.com:basaransosyal/mkbl-otomotiv.git

Adım 1.2: IT Ekibinin Sunucuda SSH Anahtarı Üretmesi

IT ekibi Linux sunucuda şu komutla sunucuya özel okuma anahtarı oluşturur:

ssh-keygen -t ed25519 -C "mkbl-server-deploy"
cat ~/.ssh/id_ed25519.pub

Çıkan genel anahtarı (ssh-ed25519 ...) proje sahibine iletirler. Proje sahibi bu anahtarı GitHub reponun Settings ➔ Deploy keys ➔ Add deploy key kısmına ekler.

Kayıt Tipi (Type) Ad / Host Değer / Hedef (Value) Açıklama

3. Linux Sunucu Adım Adım Kurulum Kılavuzu

Adım 3.1: Gizli GitHub Depoundan Projeyi Çekme

cd /var/www
git clone git@github.com:basaransosyal/mkbl-otomotiv.git mkbloto
cd mkbloto
npm install --production=false

Adım 3.2: Ortam Değişkenleri (.env) Dosyasını Oluşturma

Proje kök dizininde .env dosyasını oluşturun ve kaydedin:

# Canlı Domain URL
NEXT_PUBLIC_SITE_URL=https://mkbloto.com

# Veritabanı Bağlantısı (SQLite varsayılandır)
DATABASE_URL="file:./dev.db"

# SMTP E-Posta Bildirim Ayarları (Formların maile düşmesi için)
SMTP_HOST="mail.mkbloto.com"
SMTP_PORT="587"
SMTP_USER="info@mkbloto.com"
SMTP_PASS="MailSifreniz2026!"
SMTP_SENDER="info@mkbloto.com"
SMTP_ENABLE_SSL="true"

Adım 3.3: Veritabanını Oluşturma & Üretim Derlemesi (Build)

# SQLite veritabanı tablolarını ve seed verilerini yükler
npx prisma db push

# Next.js canlı üretim derlemesini basar
npm run build

Adım 3.4: PM2 Process Manager İle Servisi Başlatma

pm2 start npm --name "mkbl-web" -- start -- -p 3000
pm2 save
pm2 startup

Adım 3.5: Nginx Reverse Proxy & Certbot SSL Kurulumu

# /etc/nginx/sites-available/mkbloto.com dosyası oluşturun:
server {
    server_name mkbloto.com www.mkbloto.com;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}

# Nginx aktif edip Ücretsiz Let's Encrypt SSL sertifikasını yükleyin:
sudo ln -s /etc/nginx/sites-available/mkbloto.com /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d mkbloto.com -d www.mkbloto.com

Müşterilerinizin Web Siteden (Servis Randevusu, Test Sürüşü ve Showroom İletişim Formları) gönderdiği maillerin kurumsal kutunuza (info@mkbloto.com) düşmesi için 2 yöntem bulunur:

💡 ÖNEMLİ İPUCU (Yönetim Paneli Kolaylığı): SMTP sunucu ayarlarını koda dokunmadan doğrudan canlı sitenizin Admin Paneli ➔ Site Ayarları ➔ E-Posta & Bildirim Ayarları sekmesinden tek tıkla yapabilir ve "E-Posta Gönderimini Test Et" butonuyla maillerin ulaştığını anında canlıda test edebilirsiniz!
Mail Sunucu Seçeneği SMTP Host Port Güvenlik Yapılandırma Adımı
Kurumsal cPanel Mail mail.mkbloto.com 465 veya 587 SSL / TLS Sunucunuzdaki cPanel e-posta hesabınızın şifresini yazın.

Google Workspace / Gmail smtp.gmail.com 587 STARTTLS Google Hesabında 2FA açıp "Uygulama Şifresi" tanımlayın.
