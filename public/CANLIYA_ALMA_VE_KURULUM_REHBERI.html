Hosting, VPS Sunucu, SMTP Mail & API Kurulum Adımları

1. Ortam Değişkenleri (.env) Yapılandırması

Sunucuya canlıya almadan önce projenin kök dizininde bir .env dosyası oluşturulmalı ve canlı bilgiler tanımlanmalıdır: 

# Veritabanı Bağlantısı (SQLite varsayılandır. PostgreSQL için postgresql://... yazılabilir)
DATABASE_URL="file:./dev.db"

# Admin Paneli Giriş Bilgileri (Canlıda güçlü şifre belirleyin)
ADMIN_USERNAME="admin"
ADMIN_PASSWORD="GüçlüŞifreniz2026!"

# SMTP Kurumsal Mail Sunucu Ayarları (Form bildirimleri için)
SMTP_HOST="mail.mkblotomotiv.com"
SMTP_PORT="465"
SMTP_USER="info@mkblotomotiv.com"
SMTP_PASS="MailSifreniz2026!"
SMTP_SENDER="MKBL Otomotiv <info@mkblotomotiv.com>"
SMTP_ENABLE_SSL="true"

# Dış API Anahtarları (Opsiyonel - Admin Panelinden de girilebilir)
COLLECT_API_KEY="apikey sizin_collectapi_anahtariniz"
EPIAS_USERNAME="mkblsosyal@gmail.com"
EPIAS_PASSWORD="Basaran+2026"
EPIAS_API_KEY=""

2. Sunucu & Hosting Kurulum Seçenekleri

A. Vercel veya Netlify İle Kurulum (En Kolay & Ücretsiz SSL)

  1. Projeyi GitHub / GitLab deponuza yükleyin.
  2. Vercel.com paneline girip "New Project" deyin.
  3. Yukarıdaki .env değişkenlerini Vercel Environment Variables kısmına ekleyin.
  4. Deploy butonuna basın. Otomatik SSL ve CDN ile 1 dakikada canlıya alınır.

B. Ubuntu / Linux VPS (DigitalOcean, AWS, Hetzner) İle Kurulum

  1. Node.js 18+ & PM2 Kurulumu: 
    curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs
sudo npm install -g pm2
  2. Projenin Çekilmesi & Derlenmesi: 
    git clone https://github.com/kullanici/mkbl-otomotiv.git
cd mkbl-otomotiv
npm install
npx prisma db push
npm run build
  3. PM2 İle Arka Planda Başlatma: 
    pm2 start npm --name "mkbl-web" -- start
pm2 save
pm2 startup
  4. Nginx Proxy & Certbot SSL Kurulumu: 
    sudo apt install nginx certbot python3-certbot-nginx
# Nginx konfigürasyonunda location / { proxy_pass http://localhost:3000; } ayarlayın
sudo certbot --nginx -d mkblotomotiv.com

C. cPanel / Plesk Node.js Hosting İle Kurulum

  1. cPanel'de "Setup Node.js App" menüsüne girin.
  2. Node.js Sürümünü 18.x veya 20.x seçin. App Root klasörünü belirleyin.
  3. Dosyaları cPanel File Manager ile yükleyin (node_modules ve .next hariç).
  4. cPanel Terminal'den npm install, npx prisma db push ve npm run build komutlarını çalıştırın.
  5. Restart Application butonuna basarak uygulamayı başlatın.

3. Kurumsal E-Posta (SMTP Mail Sunucusu) Ayarları

İletişim, online servis randevusu ve test sürüşü formlarının e-posta bildirimi olarak gelmesi için SMTP ayarlarının yapılması gereklidir:

Sağlayıcı SMTP Host Port Güvenlik Notlar
cPanel Kurumsal Mail mail.domaininiz.com 465 SSL / TLS (Active) Hosting firmanızın verdiği e-posta şifresini kullanın.
Yandex Kurumsal Mail smtp.yandex.com 465 SSL (Active) Yandex Hesap Ayarları'ndan "Uygulama Şifresi" üretin.
Gmail (Google Workspace) smtp.gmail.com 587 veya 465 STARTTLS / SSL 2 Adımlı Doğrulama açıp "Uygulama Şifresi" alın.

SMTP ayarlarını Admin Paneli ➔ Site Ayarları ➔ Genel Bilgiler sekmesinden veya .env dosyasından istediğiniz zaman değiştirebilirsiniz.

4. EPİAŞ & CollectAPI Canlı Veri Aktivasyon Adımları

  1. Admin paneline giriş yapın: http://domaininiz.com/admin
  2. Site Ayarları ➔ Tasarruf Hesaplayıcı sekmesine geçin.
  3. CollectAPI Benzin Fiyatı: CollectAPI.com adresinden ücretsiz veya paket API key alıp yapıştırın ve switch'i ON (Aktif) konuma getirin.
  4. EPİAŞ Elektrik Fiyatı: EPİAŞ Şeffaflık Portalı Kullanıcı Adı, Şifre veya API Key bilginizi girip switch'i ON (Aktif) konuma getirin.
  5. Üstteki "⚡ Veri Akışını Test Et" butonuna basarak yeşil ışığın 🟢 VERİ AKIŞI AKTİF yandığını doğrulayın.

5. Yayın Sonrası Kontrol Listesi (Checklist)

  • ✅ Sitede SSL (HTTPS) sertifikasının aktif olduğunu doğrulayın.
  • ✅ Test sürüşü ve servis formunu doldurup SMTP e-postanın ulaştığını kontrol edin.
  • ✅ Admin paneli şifresini canlı ortamda güçlü bir şifre ile değiştirin.
  • ✅ Tasarruf hesaplayıcısında canlı piyasa verilerinin doğrulandığını görün.
